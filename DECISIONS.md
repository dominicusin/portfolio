# Решения (ADR)

- ADR-0001: один канонический репозиторий на артефакт; остальные — archive/mirror с указанием канона.
- ADR-0002: CI tiering — tier1 блокирует merge, tier2 информационный, scheduled не создаёт issue.
- ADR-0003: Wagtail — канонический сайт NeoAllUnity; legacy Django — freeze.
- ADR-0004: issue `surypus` — один трекер, дубли закрываются, робо-отчёты вынесены в отчёты.
- ADR-0005: форки — upstream policy или archive.
- ADR-0006: запрет «ложного done»: без evidence статус BLOCKED.
- ADR-0007: один ресурс — один менеджер конфигурации (Polyglot CM).
- ADR-0008: лицензии — MPL-2.0/MIT для кода, CC-BY-4.0 для контента, Unlicense для личных конфигов; существующие лицензии — grandfathering.
- ADR-0009: `portfolio` = SoT технического состояния; `dominicusin/.github` = reusable workflows; Linear = SoT задач; Notion = управленческий граф.
